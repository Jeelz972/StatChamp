Migration mono → multi-équipe

Ce script migre les données de l'ancienne structure plate vers la nouvelle structure multi-équipe. Les anciennes collections ne sont pas supprimées.

⚠️ Exécutez ce script UNE SEULE FOIS. Il est idempotent (réexécutable sans risque) mais n'opère aucune suppression. Vérifiez les données dans Firebase après migration.
